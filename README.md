# Waypointer

A web tool for making maps (built with region-style maps in mind). Create or load assets, drag and drop them onto a canvas, and export the result as JSON or SVG.

Hosted at https://coralis.github.io/Waypointer/

## Planned features
- Create/load custom assets
- Drag-and-drop canvas
- Export to JSON (editable) and SVG
- Import JSON to resume work

## Development
Plain static HTML/CSS/JS, no build step. Open `index.html` or run `python3 -m http.server`.
